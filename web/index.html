how it works

your devices, bridged to your devtools

plug in a phone. webbridge discovers every webview and streams it straight through to chrome devtools or safari web inspector.

what's inside

a full inspector, not a launcher

webbridge speaks the chrome devtools protocol itself, so the essentials live in the app. the heavyweight tools stay one click away.

a real console

levels, live filtering, saved filters, find-and-highlight, and a javascript repl that evaluates in the live page.

network + HAR

every request, method, status and size. export the session to a HAR file for any bug report.

storage at a glance

cookies, localStorage and sessionStorage. read the page's persisted state at a glance.

device logs, side by side

logcat and idevicesyslog, streamed beside the webview console. filter by source and level to see native and web together.

knows the framework

webbridge tags each webview with what it's running. if a target won't appear, it tells you how to make it inspectable.
